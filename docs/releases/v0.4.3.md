# MailWhere v0.4.3 — logo and portable discoverability patch

Status: implemented in repo and ready for release.

## What changed

- The supplied `MailWhereLogo.png` is now reflected in app/documentation branding and the generated multi-size `.ico` used by exe/window/tray surfaces.
- Portable publishing keeps the stable multi-file package, but updates the published `MailWhere.exe` modified time immediately before creating the zip.
- The touch behavior is inline in `scripts/publish-portable.sh` and `scripts/publish-portable.ps1`; no extra helper script is copied into the release payload.
- Users who extract the portable folder and sort by recent modified time should see `MailWhere.exe` near the top.
