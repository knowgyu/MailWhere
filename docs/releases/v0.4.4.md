# MailWhere v0.4.4 — archive recovery, reply progress, export SDK

Status: implemented in repo and prepared for the v0.4.4 patch release.

## Shipped

- **보관함**: 보관한 업무를 별도 창에서 보고, 원본 메일을 열거나 업무 보드로 복원할 수 있습니다.
- **다자 요청 회신 현황**: 여러 수신자에게 보낸 회신 요청은 Outlook 대화 ID와 보낸 사람 표시명을 기준으로 `n/m명 회신` 진행률을 계산합니다.
- **Export SDK/API**: `MailWhere.Core.Export.MailWhereExportService`가 open/archive/review/reply-progress snapshot을 안전한 DTO/JSON으로 제공합니다.
- **Storage/API 확장**: `IFollowUpStore`에 archive list/restore, reply observation, reply progress list 계약을 추가했습니다.
- **Privacy boundary**: export는 source id/hash, raw body, evidence snippet, 전체 수신자 목록을 내보내지 않습니다.

## Verification

- `dotnet build MailWhere.sln --no-restore`
- `dotnet run --project tests/MailWhere.Tests/MailWhere.Tests.csproj --no-build`
- `scripts/verify-static.sh`
- `scripts/publish-portable.sh`

## Limitations

- 회신 현황은 Outlook `ConversationID`와 display-name normalize 매칭에 의존합니다. 이름 표기가 크게 다르면 놓칠 수 있습니다.
- v0.4.4 이전에 이미 생성된 waiting task는 대화/수신자 metadata가 없을 수 있어 재스캔/재생성이 필요할 수 있습니다.
