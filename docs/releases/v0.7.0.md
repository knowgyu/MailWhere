# MailWhere v0.7.0 — Waiting closure and weekly review

## What changed
- Added waiting-closure suggestions for `WaitingForReply` tasks when the requested recipient replies in the same Outlook conversation.
- Added user-acknowledgement closure suggestions when the user replies in the same thread with receipt/confirmation/thanks language.
- Closure suggestions are explicit Yes/No prompts only: Yes archives the local MailWhere task, No dismisses the suggestion; Outlook source mail remains read-only and unchanged.
- Added optional LLM-backed closure judgment so weak replies like “확인해보겠습니다” can be rejected before showing a closure suggestion. If LLM is disabled or fails, MailWhere falls back to bounded deterministic rules.
- Added a lightweight weekly review summary for new tasks, archived tasks, open work, review candidates, aged waiting items, and active closure suggestions.
- Kept scan performance bounded by loading waiting tasks once per prepared batch and evaluating closure only for same-conversation, non-duplicate candidate mail.
