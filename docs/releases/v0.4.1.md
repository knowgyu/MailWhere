# MailWhere v0.4.1

## Highlights

- Direct `MailWhere.exe` launch opens the unified 업무 보드, while Windows startup uses tray-only `--tray`.
- Board/header rows are more compact and the scan-progress area no longer makes the header buttons jump.
- Settings are reorganized into tabs: `기본`, `알림`, `AI 분석`, `개발자 도구`.
- Normal settings now expose simple choices only: recent mail range `7/30/90일`, reminder timing `끄기/당일만/하루 전부터`, and no max-mail-count/startup-delay fields.
- AI endpoint/model fields start empty with hints instead of prefilled local model assumptions.
- Review candidates can run `AI 실패 후보 다시 분석` after an LLM endpoint comes back.
- Core refactor: settings choices, startup launch mode, and review-candidate retry are now reusable outside WPF for later SDK/skill integration.
