# MailWhere v0.13.1 — Full default-mailbox search and faster triage

## Changed

- Mirrors every regular mail folder recursively under Classic Outlook's default store.
- Excludes Online Archive and other separate stores, plus virtual search folders that would duplicate messages.
- Keeps Inbox/Sent classification and filters; other default-store folders appear under `전체` as `기타 폴더`.
- Shows source mail time on task and review rows.
- Groups review candidates when sender matches and normalized titles differ only by numbers.
- Applies `모두 등록`, `모두 나중에`, and `모두 무시` sequentially to grouped candidates.
- Defaults manual board opening to `이번 주`.
- Includes undated work created within the last seven days in `이번 주`; older undated work appears in `미정 backlog` without a fabricated due date.
- Prevents any review-row button double-click from opening the source mail and accepts single-key shortcuts through Korean IME processing.

## Preserved boundaries

- Outlook access remains read-only.
- Mail bodies and FTS5 stay local in `followups.sqlite`.
- CLI/provider/skill exports remain sanitized and body-free.
- External LLM access remains opt-in and Qwen3.8 probe-gated.

## Verification

```bash
dotnet test MailWhere.sln

```

Real Classic Outlook validation remains required for recursive default-store traversal, Online Archive exclusion, grouped review controls, Korean IME shortcuts, and source-open behavior.
