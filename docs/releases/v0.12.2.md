# MailWhere v0.12.2 — local LLM analysis stabilization

## Changed

- Added strict JSON Schema output contracts for OpenAI-compatible Chat Completions and Responses calls; vLLM Chat Completions is the recommended local provider.
- Retries one transient HTTP/timeout failure, then retries failed or partial batches one mail at a time without creating duplicate tasks.
- Keeps rule fallback opt-in: fallback proposal popups are off by default and the Settings window exposes their visibility separately from the selected failure policy.
- Caps LLM payload context: current message 1,300 characters, forwarded context 900 characters only when relevant, and quoted reply history 240 characters.
- Preserves idempotent FTS mirror writes and documents the local-first maintenance boundaries.
