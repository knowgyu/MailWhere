# MailWhere v0.13.2 — Qwen3.8 non-thinking sampling alignment

## Changed

- Applies the official `Qwen/Qwen3.8-27B` non-thinking sampling profile to verified MailWhere requests: `temperature=0.7`, `top_p=0.8`, `top_k=20`, `presence_penalty=1.5`, and `repetition_penalty=1.0`.
- Keeps sampling request-scoped so a shared vLLM server can retain its thinking-mode defaults for other clients.
- Applies the same profile to Chat Completions and Responses calls used by single analysis, batch analysis, and waiting-closure judgment.
- Leaves `seed`, preserved-thinking history, and streaming unset because MailWhere performs independent, complete JSON classifications.
- Versions the LLM request contract in the probe fingerprint, invalidating older proof and requiring the analysis-shaped connection test again after upgrade.

## Preserved boundaries

- Outlook access remains read-only.
- Mail bodies and the FTS5 mirror stay local.
- CLI/provider/skill exports remain sanitized and body-free.
- External LLM access remains opt-in, sequential, and fail-closed behind the synthetic single/batch/closure probe.
- Server-wide vLLM defaults are not changed.
