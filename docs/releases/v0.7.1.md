# MailWhere v0.7.1 — Header cleanup for closure and weekly review

## What changed
- Removed the separate `보관 제안` and `주간 리뷰` buttons from the main board header to keep the top action area light.
- Folded active closure suggestions into the existing `확인 필요` count. If only closure suggestions are pending, clicking `확인 필요` opens the closure prompt directly.
- Moved `보관 제안 확인` and `주간 리뷰` to the tray menu as secondary/occasional actions.
