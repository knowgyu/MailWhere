# MailWhere v0.11.1 — Production mail mirror sync

## What changed

- Wired the existing Inbox/Sent mirror into the supported **지금 메일 확인** Windows flow.
- Reused the existing progress UI and stop action for cancellable, resumable full-history indexing.
- Added checkpoint-based incremental catch-up for automatic/event checks.
- Added manual and bounded 24-hour authoritative reconciliation for Outlook moves and deletions.
- Kept mirror progress content-free and kept `search-mail --json` SQLite-only.

## Safety and performance

- Outlook access remains read-only.
- Initial and incremental writes remain serialized in batches of at most 25.
- Warning-bearing inventory never advances successful cadence markers or deletes unseen mirror rows.
- Mirror state stores only two timestamps:
  `mail-mirror-initial-sync-completed-at` and
  `mail-mirror-last-authoritative-reconcile-at`.
- No new project, dependency, background worker, CLI Outlook dependency, attachment indexing, embedding, or contextWhere body copy was added.
