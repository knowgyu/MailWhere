# MailWhere v0.8.0 — Event-driven lightweight mail checks

## What changed
- Added Outlook ItemAdd event watching for Inbox and Sent Items. Events trigger a short debounced background check.
- Kept automatic timer fallback so missed Outlook events, sleep/wake gaps, and Outlook restarts are still covered.
- Split automatic scan cursors for Inbox and Sent Items while keeping the legacy cursor populated for compatibility.
- Added metadata-first fast filtering for automatic delta checks: already processed and in-batch duplicate source hashes are skipped before body/LLM analysis, while initial catch-up scans stay straightforward.
- Moved waiting-closure decisions into the existing 확인 필요 window as `보관(Y)` / `유지(N)` rows.
- Hardened rapid review actions with busy-row protection and optimistic row removal.
