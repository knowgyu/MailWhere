# MailWhere v0.7.2 — Short scan options and local data reset

## What changed
- Added **최근 1일** as a scan range for lightweight manual checks.
- Added **1분마다** as an automatic mail check interval, while keeping the read-only safety gate.
- Restored a settings-window **로컬 업무 데이터 삭제** action under developer tools. It deletes local task/review/processed-source DB files and keeps `runtime-settings.json`.
- Updated portable docs and seed samples to explain automatic checks, local data reset, and team default settings sharing.

- Release tag: `v0.7.2`

- Manual **지금 메일 확인** uses the configured range. Automatic checks use the last successful scan cursor after the initial run, so they avoid rereading the whole configured range every interval.
