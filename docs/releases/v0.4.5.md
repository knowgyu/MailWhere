# MailWhere v0.4.5 — LLM telemetry and edit reliability patch

## What changed
- Recorded Ollama `/api/chat` response metadata already returned by the server: total/load/prompt/eval durations, token counts, and thinking text length.
- Made LLM scan status clearer by separating request count/average from item-level success/failure counts.
- Reduced requested LLM output by removing redundant `summary` and `evidenceSnippet` fields from the prompt schema while keeping legacy parsing compatible.
- Raised LLM temperature to `0.1` for slightly less brittle JSON classification behavior.
- Added adaptive scan batching: short mail can batch larger and long mail batches smaller.
- Fixed final-action idempotency so approved/ignored review items and archived/completed/dismissed tasks mark their source as processed.
- Repaired task double-click edit targeting and edit dialog sizing/Enter/Esc handling.
